# Changelog

## [1.0.0] - 2026-06-05

### Initial stable release

- local-first Home Assistant integration for compatible Bambu Lab 3D printers
- LAN-only, Cloud-only and Hybrid setup modes
- manual printer IP address with optional automatic-discovery fallback
- MQTT telemetry and printer controls
- native Home Assistant camera support where available
- responsive Lovelace cards
- local 3MF archive and SD-card FTPS file management where supported
- persistent 3D print queue with quantity selection
- direct Bambu Studio handoff using unchanged original 3MF files
- German and English setup translations
- selectable German, English or automatic dashboard language
- public HACS repository structure and validation workflows
