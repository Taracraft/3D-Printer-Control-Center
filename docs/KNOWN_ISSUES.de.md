# Bekannte Probleme

## Automatische Netzwerkerkennung

Die automatische Erkennung kann in gerouteten VLANs, VPNs, Site-to-Site-Verbindungen und Netzen mit gefilterten Broadcasts unzuverlässig sein. Trage die Drucker-IP bei der Einrichtung oder später in den Integrationsoptionen manuell ein. Eine manuelle IP hat Vorrang vor dem automatischen Scan.

## Abdeckung weiterer Druckermodelle

Version `1.0.0` wurde praktisch mit einer Bambu-Lab-A1-Umgebung getestet. MQTT-Telemetrie, SD-Karten-Zugriff per FTPS und native Kameraunterstützung hängen von Druckermodell und Firmware ab.
